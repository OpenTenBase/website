从数据库内核优化到 Agent 生产落地，从开源技术探索到一线工程实践——2026 年 8 月 29 日 14:00，开放原子技术沙龙·OpenTenBase 城市行杭州站将在杭州举行。7 场技术分享、1 场 TXSQL Workshop，邀你共同探索数据库智能化的下一站。

## 活动速览

AI 时代，数据库正在从“存数据的底座”进化为“智能体的记忆中枢、推理底座和运维决策核心”。

8 月 29 日，开放原子技术沙龙·OpenTenBase 城市行杭州站与你相约。本次活动汇聚数据库内核、AI 智能体、企业级开源实践的多位一线技术专家，围绕 TXSQL 自学习优化器、分布式 SQL 调优、Agent Memory 开源、数据库 Agent 生产落地等前沿议题，带你看清数据库与 AI 融合的当下与未来。

**时间：** 2026 年 8 月 29 日（周六）14:00 - 18:30

**地点：** 杭州西溪紫金港希尔顿花园酒店二层【花园厅】

**主办单位：** OpenTenBase 社区、腾讯云

## 为什么值得你来？

- 看懂数据库智能化的两条技术路径：内核自治优化与 Agent 工程化；
- 获得分布式 SQL 调优、数据库 Agent 安全上线等可复用的方法框架；
- 现场了解 Agent Memory 开源架构、团队记忆设计和社区 Roadmap；
- 参与 TXSQL 实践 Workshop，与数据库内核、DBA 及开源社区专家面对面交流。

## 议程亮点抢先看

### AI 与智能体时代 OpenTenBase 开源社区演进

**单致豪｜腾讯开源 TOC 主席，OpenTenBase 社区秘书长**

在 AI 与智能体浪潮下，开源社区如何持续演进、连接开发者与产业实践？单致豪将从社区战略视角，分享 OpenTenBase 在智能体时代的技术布局、生态建设与开源治理思路，为开发者和企业参与者勾勒一幅清晰的社区路线图。

OpenTenBase 社区　AI 战略　开源生态

### TXSQL 自学习优化器 - 数据库智能查询优化落地实践

**李天峰｜腾讯数据库高级研发工程师**

数据库性能调优长期依赖资深专家经验，一条慢查询往往耗费大量人力反复排查，成为制约业务规模化交付的隐形瓶颈。李天峰将带来一个全新答案：把顶尖专家的调优智慧沉淀进 AI，让数据库主动发现问题、推理根因、给出最优方案。

然而大模型天然存在“幻觉”，为此团队将 AI 推理能力与数据库内核深度结合——依托持续负载监控、增量优化、防回退以及计划管理、计划演进等内核技术，构建起安全可控、自我闭环的智能优化体系，既能释放大模型推理智慧，又能有效驯服幻觉、守住稳定底线，真正实现从“人工调优”到“智能自治”的跨越。

TXSQL　自学习优化器　智能自治　防回退

### 我的 AI 屠龙刀

**德哥（周正中）｜腾讯云架构师同盟成员，前阿里高级数据库专家**

进入 AI 时代，人人都应该打造一把适合自己的趁手兵器，最大化放大潜能与想象力，把想象力变成可交付的产品与服务。德哥将围绕 Agent、Skill、MCP、记忆模块、代码地图与多智能体编排，分享如何打造一套可日常稳定交付的自动化工作流，并让它自我进化、越用越好。

作为 PostgreSQL 中国社区发起人之一、拥有 40 余项数据库领域专利的开源老兵，他的分享兼具实战厚度与个人风格。

Agent　Skill　MCP　记忆模块　自动化工作流

### WorkBuddy 助力：pg_hint_plan 性能优化实战 — hint_table 缓存重构性能提升 38%

**杨向博｜腾讯云 DBA，PostgreSQL ACE**

hint_table 是 pg_hint_plan 中通过 SPI 访问的普通 heap 表，高并发下存在连接开销、性能抖动、污染 QPS 统计等问题。杨向博将分享如何提出 Local HashTable 及 DSM HashTable 访问特性，并借助 WorkBuddy 完成“一站式需求实现→自动测试验证迭代→最终高质量交付”的完整链路，最终实现约 38% 的性能提升。

这也是 AI 编程工具赋能数据库内核优化的真实落地案例。

pg_hint_plan　hint_table　WorkBuddy　性能优化

### 打破分布式 SQL 性能瓶颈｜OpenTenBase 优化器与 SQL 调优实战

**郭一军｜云贝教育创始人，公众号“DBA 面试君”主理人**

分布式数据库时代，SQL 性能瓶颈已从单机 CPU/IO 转向网络通信、数据重分布与分布式计划生成。郭一军——25 年数据库老兵，深度服务银行、证券、基金、保险四大领域 TOP10 头部机构——将深入剖析 OpenTenBase 分布式优化器的内部机制，结合真实生产环境中的慢 SQL 案例，从执行计划解读、分片键设计、分布式 Join 优化到参数调优，提供一套经生产验证的 SQL 性能调优方法论。

OpenTenBase　分布式优化器　SQL 调优　分片键设计

### 从个人记忆到团队资产：Agent 记忆的进化与开源之路

**谭琬潼｜腾讯云数据库产品经理**

Agent 走向长程任务，“记忆”正在成为能力天花板。传统方案或暴力截断上下文，或将历史无脑堆入向量库，代价是高昂的推理成本与失控的幻觉率。

TencentDB Agent Memory 以 MIT 协议完全开源，零外部 API 依赖、本地即可部署，并坚持框架中立。本次分享将完整拆解其架构：符号化短期记忆最高降低 61% Token 消耗、任务通过率相对提升 51%；L0-L3 分层长期记忆将碎片对话层层提炼为用户画像，PersonaMem 准确率从 48% 提升至 76%；新版本更将首次介绍团队记忆能力，并公开开源 Roadmap 与社区共建路径。

Agent Memory　开源　符号化记忆　团队记忆

### 内生智能数据库前瞻技术研究

**吕海波｜易景科技首席研究员，北京大学企业导师**

从 CPU 到 GPU，再到 LPU 等新型处理器，“推理计算”的底层范式正在发生深刻变化。吕海波——30 年 IT 软件行业经历，曾在阿里、京东、eBay 等企业从事数据库架构与研发，长期在北京大学讲授研究生课程《开源软件开发基础与实践》——将梳理计算硬件的发展脉络，结合国内著名计算芯片案例，剖析 AI 时代“算力”的最核心瓶颈：访存延迟，并探讨冗余计算单元、隐藏访存延迟等破局之道，最终回归数据库在 AI 时代的危机与机遇。

内生智能数据库　LPU　访存延迟　算力瓶颈

### AI 会写 SQL 了，然后呢？——数据库 Agent 从 Demo 到生产的五道关

**童天宇｜开源数据库工具 DBX 作者**

大模型已经能够快速生成 SQL，但“会写 SQL”并不等于“能够安全操作生产数据库”。当 Agent 开始选择连接、理解表结构、生成不同数据库方言并尝试执行时，真正的工程问题才刚刚开始。

童天宇将结合开源数据库工具 DBX 的实践，从上下文、兼容性、权限、风险、执行五个维度，拆解数据库 Agent 从 Demo 走向生产必须通过的五道关，并给出一套可用于方案设计和上线评估的检查框架。

数据库 Agent　DBX　生产落地　安全执行
