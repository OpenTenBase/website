## 议程亮点抢先看

### 智能体落地实践：多模融合知识底座如何让企业 AI 少走弯路

魏波｜北京晟数科技技术顾问，中国 PostgreSQL 分会副秘书长

企业级 AI 智能体通常要同时搞定向量、全文检索、图关系、缓存和结构化数据，于是架构越堆越复杂：Milvus + Redis + ES + Neo4j + 关系型数据库，运维负担肉眼可见。

魏波将从真实智能问数项目出发，拆解五组件架构的工程痛点，展示 PG 多模扩展（pgvector、tsvector、Apache AGE）如何把这些能力收敛到一个引擎，并分享 OpenTenBase 在这一方向上的技术探索与生态共建思路。如果你正在为企业 AI 选数据底座，这场分享能帮你少走一大段弯路。

**关键词：** 多模融合、知识底座、Agent 数据架构、OpenTenBase 生态

### 拥抱 100X 列存技术：AI 时代下的 TXSQL 进化和生态突围

陈开旺｜腾讯云后台开发工程师，TXSQL 内核委员会成员

当大模型让「写代码」变容易，系统长期稳定的挑战反而更严峻。陈开旺将从「编程的本质是否被 AI 改变」这一哲学问题切入，带你深入 TXSQL 列存引擎——不是渐进优化，而是 100 倍性能跃升的技术范式。

分享将拆解超强压缩比、列裁剪、批量处理与向量化计算的底层原理，用实测数据对比行存与列存的百倍差距；同时直面 DDL 变更、数据校对等业务可用性难题，并展望湖仓一体、外表接口与 TXSQL 扩展生态的演进方向。

**关键词：** TXSQL 列存、100 倍性能、向量化计算、湖仓生态

### 大模型赋能智能运维：智能体助力数据库性能优化落地实践

陈卫星｜北京神脑资讯技术有限公司 CEO，腾讯 OpenTenBase ACE

数据库运维的深夜告警、慢查询、参数调优，能不能让智能体扛起来？陈卫星将从一个真实的深夜告警场景切入，给出大模型 + 智能体在数据库运维中的完整答案。

内容包括智能运维系统的分层架构、智能体从感知到行动的技术链路，并重点拆解两大落地场景：慢查询智能诊断与优化、数据库参数智能调优。同时，他也会坦诚分享大模型幻觉、安全风险、组织流程适配等真实挑战与应对策略，给出一套从 0 到 1 建设智能运维能力的路线图。

**关键词：** 智能运维、慢查询优化、参数调优、大模型落地避坑

### TencentDB Agent Memory 的开源实践与架构探索

谭琬潼｜腾讯云数据库产品经理

Agent 走向长程任务，「记忆」正在成为能力天花板。传统方案要么暴力截断上下文，要么把历史无脑塞进向量库，导致推理成本高、幻觉失控。

TencentDB Agent Memory 以 MIT 协议完全开源，零外部 API 依赖、本地即可部署，框架中立。本次分享将完整拆解其架构：符号化短期记忆把工具日志异步压缩为 Mermaid 任务画布，最高降低 61% Token 消耗、任务通过率相对提升 51%；L0-L3 分层长期记忆将碎片对话提炼为用户画像，PersonaMem 准确率从 48% 提升至 76%。此外，新版本还将首次介绍团队记忆能力，并公开开源 Roadmap 与社区共建路径。

**关键词：** Agent Memory、开源、符号化记忆、分层长期记忆、团队级记忆

### OpenCode + Skills + Grafana MCP 数据库告警智能分析实践

张松鹤｜敦煌网 DevOps 工程师

告警来了，先看哪个指标？面板怎么调？结论怎么推？敦煌网的实践给出了一个全开源、低门槛的解法：以 OpenCode 作为 Agent runtime，结合 Grafana MCP Server 和告警分析 Skill 工作流，让 Agent 自动匹配面板、分析告警、给出结论，并通过飞书推送结果。

这套方案不绑定任何厂商，组件全开源，扩展性强，已在大规模 MySQL 告警分析中验证效果。张松鹤将分享项目背景、实现过程、最佳实践与未来展望，给你一个可直接参考的生产落地案例。

**关键词：** OpenCode、Grafana MCP、告警智能分析、全开源、DevOps

### AI 智能体 + 数据库：QClaw & OpenTenBase 全流程实战

张瑞｜腾讯云开发者社区技术产品运营，QClaw 产品布道师，OpenTenBase 核心贡献者

QClaw 是什么？它和 OpenTenBase 能擦出怎样的火花？张瑞将带来一场全流程实战分享，演示 AI 智能体与数据库如何协同工作，从场景搭建到任务执行，把「智能体 + 数据库」真正跑通。

作为 QClaw 产品布道师，他还将分享腾讯云社区 AI 公开课在全国十余座城市的落地经验，以及企业级 AI 办公范式升级的实践路径。

**关键词：** QClaw、OpenTenBase、AI 智能体、全流程实战
